01

Google 終止支援時程

  • • 已停收新戶：新專案無法再開通 Custom Search JSON API 服務。
  • • 現存客戶限期：既有 API Key 最晚僅能運作至 2026 年底。
  • • 倒數關鍵期：距正式斷線僅存約一季充裕測試轉移窗口。

為何官方「不再提供全網 API」？

  • • AI 數據護城河：防止競爭對手以低廉代價（$5/千次）爬取 Google 搜尋庫訓練 AI。
  • • 保護廣告核心營收：鼓勵使用者回到 google.com 首頁產生廣告曝光。
  • • 全面押注企業高單價平台：重心移轉至 Vertex AI 高階合約。

  • ! 單一 API 時代終結：需將「站內規格檢索」與「全網即時搜尋」正式分流。
  • ✓ 系統升級契機：引進 Adapter 架構與內文提取，全面強化 Agent 準確度。

Chapter 02 · 官方解方

Agent Search 可用的解決方案

專注於可控站點（< 50 Domain）的頂級語意檢索與過渡呼叫方案

Google Cloud 原生託管

1 Website Data Store（站點資料庫架構）

將公司常用外部站點（如 JEDEC, SEMICON, 專利局, 設備大廠官網）集中索引。

Basic Indexing (推薦) 借用 Google 全網現存索引，無需網域所有權驗證，隨開即用，成本低。
Advanced Indexing 需 Google Search Console 網域驗證，僅適用自家企業門戶，成本較高。
⚠️ 關鍵邊界：50 Domain 上限 單一 Website Data Store 官方規格限定約 50 個 Root Domain。因此 Agent Search 適用於高權威核心站點，不適合漫無目的長尾搜尋。

2 接口演進：searchLite 快速過渡 → search 正式上線

指標 searchLite (過渡階段) search (目標架構)
認證模式 API Key (與舊版相同) OAuth 服務帳號 Token
遷移成本 極低 (半天即可跑通) 中等 (需掛載憑證生命週期)
功能支援 公開網站檢索 (Title/Snippet) 私有文件、AI 摘要、權限控管
落地戰術： 10 月先透過 searchLite 完成初步對接，確保服務不中斷；11~12 月切換為企業級 OAuth Service Account。
Chapter 03 · 決策分析

自建 Google 爬蟲之困境 vs. 第三方規模優勢

為何企業「自建爬蟲」是高成本負資產？為何外部專業供應商能做到極致低價穩定？

Build vs Buy 關鍵評估
✕

自建 Google 爬蟲的 4 大死穴

  • 1. 機房 IP 秒封與 CAPTCHA 阻斷 GCP/AWS 雲端主機請求數十次即被識別為機房流量，強制彈出 reCAPTCHA 或 429 拒絕。外購住宅代理（$3~$8/GB）成本甚至直接超越 API！
  • 2. HTML DOM 混淆與頻繁改版 Google 搜尋頁 class 高度混淆（如 .yuRUbf）且全球頻繁 A/B 測試。解析器每隔數週失效一次，工程師需 24 小時待命修復。
  • 3. 瀏覽器指紋（TLS/JA3/Headless）檢測 單純 HTTP 請求被指紋秒識破；若用 Playwright/Puppeteer 模擬，記憶體開銷龐大，單次查詢延遲暴增至 3~6 秒以上。
  • 4. 成本效益嚴重倒掛 光是買 Proxy 流量 + 主機費 + 維護人力工時，自建每千次成本輕易超過 $3 ~ $5 USD，造輪子反而貴數倍。
結論：自建爬蟲將陷入無限「貓捉老鼠」的維護泥淖
✓

第三方供應商（如 Serper）為何能輕鬆搞定？

  • 1. 超大規模經濟效益（Economies of Scale） 服務商每日消化數億次請求，以批發價向全球電信商採購數百萬顆真實家庭住宅 IP 池，單位頻寬成本趨近於零。
  • 2. 專職 24/7 反爬攻防與 DOM 解析團隊 專門工程團隊 24 小時監控 Google 全球語系 DOM 結構異動，幾分鐘內自動熱更新解析模組，研發成本由全球數萬客戶共同攤提。
  • 3. 全天候預熱管道（延遲低至 < 0.8s） 維持巨量已暖機、高併發的連接通道，無需像自建那樣每次啟動肥大的 Chrome 瀏覽器，查詢響應極快。
  • 4. 極致單價（~$1 / 千次）與零維運負擔 以標準 RESTful JSON 吐出乾淨結果，企業完全無需分心維運爬蟲，開箱即用。
結論：外購服務享有全球規模紅利，ROI 與穩定度遠勝自建
主管決策洞察： 我們是半導體/晶圓製造企業，工程能量應集中於「晶圓數據、Agent 智慧推理與核心業務」，而非浪費時間與 Google 防爬工程師對抗。

class SearchAdapter:
    def search(self, query: str, num: int = 10):
        # 1. 晶圓廠機密關鍵字脫敏檢查
        sanitized_q = self.sanitize_query(query)
        
        # 2. 智慧路由：判斷是否命中指定白名單網站
        if self.is_whitelisted_site(query):
            return self._query_agent_search(sanitized_q, num)
            
        # 3. 全網搜尋主路徑 (Serper) + 自動故障轉移 (Brave)
        try:
            return self._query_serper(sanitized_q, num)
        except ProviderError:
            return self._query_brave(sanitized_q, num)

    # 4. 輸出與舊版 customsearch.items 完全一致的資料型態
